# Example workflows

## Release photos

Select photos, preview a `IMG_` → `vacation_` find/replace, and confirm. FileForge rejects any existing target or a file modified after preview.

## Sort a download folder

Create an organization plan using extensions (`PDF`, `JPG`, and so on) or categories (`Images`, `Documents`). Review destination paths, then confirm the move.

## Investigate duplicates

Scan a selected set. Candidates are grouped by size first and then by streamed SHA-256 hash. The operation is read-only; decide manually what to retain.
