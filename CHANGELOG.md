# Changelog

## 1.0.0

- Completed Rename, Organize, Duplicates, and History interfaces.
- Added live previews, drag-and-drop, sortable file tables, shortcuts, progress, cancellation, and persistent settings.
- Added safe recursive duplicate scanning, streamed hashes, recoverable quarantine, and potential-savings reporting.
- Added serialized filesystem transactions, no-clobber cross-volume transfer, rollback, atomic journals, selectable cycle-safe undo, and stale-state validation.
- Expanded automated coverage to more than 100 tests across transformations, validation, organization, scanning, hashing, transaction failure, history, undo, and GUI startup.
- Added reproducible Windows packaging and Windows/Linux CI configuration.
